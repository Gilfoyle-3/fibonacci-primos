DOCUMENTACIÓN TÉCNICA Y CASO DE USO SOCIAL

Caso de Uso Real: El protocolo Diffie-Hellman es el cimiento de la seguridad en aplicaciones como WhatsApp o Signal. Requiere un número primo gigante ($P$) y un generador ($G$). Si $P$ no es primo real, un atacante externo puede aplicar el logaritmo discreto y descifrar la conversación completa.

Solución a la Sociedad: Este módulo actúa como un escudo de auditoría. Permite a activistas sociales, periodistas de investigación o redes comunitarias independientes validar de forma instantánea si el parámetro numérico de su arquitectura de comunicación es seguro y robusto antes de transmitir información confidencial.

  • Complejidad Temporal Pro: $O(\sqrt{N})$ con saltos indexados de paso 6. Un bucle convencional a $N$ tardaría horas con números grandes; este algoritmo corta la búsqueda en la raíz cuadrada exacta reduciendo las iteraciones en un 99.9%.
  • Estrategia de Poda: Descarta múltiplos de 2 y 3 inmediatamente en las tres primeras líneas.

[ALGORITMO CON PODA DETERMINISTA DE COMPLEJIDAD BAJA]


// Método Tryhard O(sqrt(N)) con secuencia de saltos i += 6
function esPrimoEficiente(n) {
    if (n <= 1) return false;
    if (n <= 3) return true;
    if (n % 2 === 0 || n % 3 === 0) return false;
    for (let i = 5; i * i <= n; i += 6) {
        if (n % i === 0 || n % (i + 2) === 0) return false;
    }
    return true;
}
